# Operadores Aritmeticos 
Los operadores aritméticos ejecutan operaciones matemáticas con dos expresiones de uno o varios tipos de datos. Se ejecutan en la categoría de tipos de datos numéricos. Para obtener más información sobre las categorías de tipos de datos.

|Operador|Significado|
:---:|:---:|
`+` (Sumar) | Suma
`-` (Restar)| Resta
`*` (Multiplicar)| Multiplicación
`/` (Dividir)| División
`%` (Modulo)| Devuelve el resto entero de una división

También se pueden usar los operadores más (+) y menos (-) para ejecutar operaciones aritméticas sobre valores datetime y smalldatetime.
