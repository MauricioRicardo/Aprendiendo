# JOBS
En SQL Server, un "job" se refiere a un trabajo automatizado que realiza una o más tareas de manera programada. Estos trabajos son administrados y ejecutados por el Agente SQL Server, que es un componente del servidor de base de datos de SQL Server. Los jobs son útiles para programar y automatizar tareas recurrentes, como la ejecución de consultas, el mantenimiento de bases de datos, la generación de informes y otras actividades administrativas.
