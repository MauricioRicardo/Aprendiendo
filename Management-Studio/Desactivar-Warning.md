# Desactivar Warning

Como desactivar el **Warning Prevent saving changes that require table re-created**, que no nos permite editar los tipos de datos despues de guardar la tabla:
![Warning](https://res.cloudinary.com/dtzgksveo/image/upload/v1688149671/PitooPlumo/SQL/Warning_ridorr.png "Warning Prevent Saving Changes")

* Vamos a en el menú de opciones **Tools/Options**
* Se abrirá una ventana de opciones vamos a la pestaña de **Designer**

* Desmarcamos la opcion **Prevent saving changes that require table re-creation**, como se muestra en la siguiente imagen:

![Opciones](https://res.cloudinary.com/dtzgksveo/image/upload/v1688149671/PitooPlumo/SQL/Warning2_cbsgdg.png)

* Para finalizar damos clic en el boton de **OK**
