# Tipos de Datos de Usuario

* Para crear un tipo de datos en nuestra base de datos
* Abrimos la base de datos en la carpeta de **Programmability**
* La siguiente carpeta es **Types**
* Damos clic derecho a carpeta **User-Defined Data Types**
* Seleccionamos la opción de **New User-Defined Data Type**

![Definir Tipos de Datos](https://res.cloudinary.com/dtzgksveo/image/upload/v1688499474/PitooPlumo/SQL/TipoDatos_z6cwbo.png "New User-Defined Data Type")

* Se abrirá una ventana en la cual tenemos que ingresar el **Nombre** y seleccionar **Tipo de Dato** como se muestra en la siguiente imagen:

![](https://res.cloudinary.com/dtzgksveo/image/upload/v1688502265/PitooPlumo/SQL/TipoDatos1_lhiy8p.png)

* Para finalizar damos clic en el botón de **OK**

---
## Desde Consola

```sql
CREATE TYPE nombre FROM INT NOT NULL
```
